# 使用手册

## 界面导览

主界面分两个页签：

- **字幕稿**（默认）：左边编辑器（带工具行：插入模板 / 校验格式 / 格式说明），右边控制区（翻页、暂停、逐条推进、页码条）。顶部是**预览框**：按你主屏的真实比例显示字幕条的落位与效果，导入 PPT 后背景是幻灯片，没导入也能用。
- **外观与显示**：布局（覆盖/贴边）、推进模式（滚动/逐条）、字号颜色透明度等全部设置。

顶栏状态条实时显示：字幕条是否显示 · 是否 PPT 放映中 · 条数/页数 · 保存状态。

## 三种稿件工作流

### ① 有 PPT：导入 PPT

1. 点「导入 PPT」选 `.pptx`——自动读页数、取**演讲者备注**生成字幕稿骨架（长备注按句拆条），并导出每页预览图
2. 导入后顶栏按钮切换为「打开 PPT」（可见地打开这个 deck）和「断开 PPT」
3. 编辑生成的骨架（或直接「导入译稿」换成人工译稿，页号对齐即可）
4. 播放：打开 deck → 开始放映 → 字幕条自动出现并跟随翻页、跟随放映所在的屏

### ② 有人工译稿：导入译稿

点「导入译稿」选 `.md` / `.txt`，格式见下节。`## P6 · 标题` 风格的文件会被自动转成 `=== 6 ===`。

### ③ 没有 PPT：直接写稿

1. 「插入模板」→ 照着格式改（或从空稿写起）
2. 「校验格式」确认条数/页数，有错会精确到行号
3. 预览框拖字幕条调好位置 → 点「显示字幕条」放映（预览与实际播放位置一致）
4. 没有放映跟随，翻页靠快捷键 Ctrl+Alt+←/→ 或页码条

## 字幕稿格式

```
=== 1 ===            页标记：PPT 第 1 页；页号从 1 开始
=== 3-5 ===          跨页：第 3 到 5 页共用这些字幕
# Town Hall          注释行：不显示，可写页标题、提词备注
一行就是一条字幕     太长自动折行（封顶 5 行，超出不再增高）
EN: English line     可选：跟在中文条后面，作为这一条的英文
（空行随意，不影响解析）
```

规则：

- 页号必须从 1 开始递增；第一条字幕必须出现在某个页标记之后，否则报「内容出现在第一个 === 页标记之前」
- 校验出错时提示「第 N 行：原因」；写完建议点「校验格式」
- 编辑器内容自动保存（600ms 防抖），落盘 `%APPDATA%\com.luna-jiang.windows-subtitle\store.json`

## 字幕条位置与拖动

- **预览里拖**：字幕稿页的预览框里直接拖字幕条，松手即生效，位置按屏幕比例保存
- **字幕条上拖**：放映时直接拖字幕条窗口本身，松手后位置回写（预览同步跟着动）
- **恢复默认**：预览框下方的「恢复默认位置」按钮回到底部居中
- 默认位置 = 宽度按「字幕条宽度」滑条、水平居中、距底部按「距屏幕底部」滑条；**拖动过以后位置以拖动为准**（这两个滑条停用，恢复默认后重新生效）
- 位置按比例存储，换屏/换分辨率等比适配

## 布局：覆盖 vs 贴边

- **覆盖**：字幕条浮在放映画面上（默认，底部居中）
- **贴边**：放映窗/预览窗让出一条边（上/下/左/右，占比 8%–50% 可调），字幕条整条贴在让位区，不遮挡画面；切回覆盖时目标窗自动恢复全屏

## 外观设置速览

| 设置 | 说明 |
|---|---|
| 推进模式 | 整段滚动（进页自动上滚）／逐条推进（F9 下一条） |
| 基础显示行数 | 1–5 行；内容折行超出自动增高，封顶 5 行 |
| 滚动速度 / 进页停留 / 滚完停末行 | 仅滚动模式 |
| 中文字号 / 英文字号 | 字号直接反映在预览和真实字幕条 |
| 同时显示英文行 | 显示 `EN:` 行 |
| 字幕条宽度 / 距屏幕底部 | 覆盖模式的默认几何（拖动过后以拖动为准） |
| 背景不透明度 / 背景色 / 文字色 / 圆角 / 内边距 | 背景板样式 |
| 仅文字字幕 | 无背景板，白字+阴影直接浮在画面上（字幕条区域仍会挡鼠标；需点穿下层按 Ctrl+Alt+X） |
| 文字对齐 | 居中 / 左对齐 |
| 字幕条所在显示器 | 自动（跟随放映屏）/ 指定第几块屏 |
| 鼠标点击穿透 | 默认关；穿透会把点击传给下层放映画面（点击=翻页），一般不用开 |

## PPT 跟随细节

- 依赖本机装有 PowerPoint（COM）。程序启动后每 250ms 轮询放映状态，不订阅事件
- `screen: 自动` 时字幕条跟随放映窗所在的屏（多屏演讲的常用场景）
- 放映到最后一页再向后，字幕条保持当前页不闪烁；放映结束字幕条自动隐藏（F7 可再显示）
- **断开 PPT**：关闭程序挂载的 deck、删除导入的预览图、清空字幕稿（断开=结束这一场），回到可导入下一个 PPT 的干净状态

## 常见问题

- **点了按钮没反应？** 旧版本 bug（窗口创建锁死主线程），已修复；若复现请带日志提 issue
- **字幕条挡住 PPT 点击？** 字幕条区域默认接管鼠标（为了可拖动）。要点击下层的画面区域，按 Ctrl+Alt+X 开穿透，或用贴边布局避开画面
- **双语行太长折行多？** 英文按句配对，句子天然长于中文字幕条；以中文条为准控制节奏，英文行折行属正常
- **导入后没有预览图？** PowerPoint 导出 PNG 需要本机可运行 PowerPoint；无 PowerPoint 的机器仍可用译稿+无 PPT 模式
- **数据都在哪？** 设置与稿件：`%APPDATA%\com.luna-jiang.windows-subtitle\store.json`；导入的预览图：仓库内 `app/imports/`（仅开发模式），断开时清空
