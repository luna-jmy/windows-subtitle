# Windows Subtitle · 桌面字幕条

给「有人用外语演讲、台下观众听不懂」的场景做的桌面字幕工具：把译稿按 PPT 页拆成一条条字幕，放映时字幕条悬浮在 PPT 上、跟随翻页自动推进。**没有 PPT 也能用**——写稿、显示字幕条、照常放映。

Tauri 2 + Rust + React 19，产物是单个 Windows 安装包。

## 功能一览

- **跟随放映**：PowerPoint COM 轮询（250ms），放映开始自动跟随翻页、跟随所在显示器；放映结束字幕条自动隐藏
- **两种推进**：整段连续上滚（可调速度/进页停留/滚完停末行）或逐条推进（F9/F8）
- **两种布局**：覆盖（字幕条浮在放映画面上）与贴边（放映窗让出一条边，字幕不遮挡画面），四向贴边、占比可调
- **预览 = 实际播放**：主界面预览框按真实屏幕比例渲染字幕条，位置/宽度/字号/颜色/贴边效果所见即所得；**预览里和字幕条上都可直接拖动调位置**，两处双向同步
- **三种稿件来源**：导入 PPT（自动取演讲者备注生成骨架 + 每页预览图）、导入译稿（`=== N ===` 格式 .md/.txt）、编辑器直接写（带模板插入与格式校验）
- **仅文字模式**：无背景板，白字+阴影直接浮在画面上
- **托盘**：关闭/最小化收进托盘，不占任务栏

## 快速开始

开发环境：Windows 10/11 + Node 18+ + Rust（MSVC 工具链）+ WebView2。

```bash
cd app
npm install
npm run tauri dev      # 开发运行（前端热更新，Rust 改动自动重编）
npm run tauri build    # 出 NSIS 安装包（app/src-tauri/target/release/bundle/）
```

## 字幕稿格式 30 秒上手

```
=== 1 ===            ← PPT 第 1 页（没有 PPT 就按顺序编页）
# Town Hall          ← # 开头是注释，不显示
第一句字幕（一行 = 一条，太长自动折行，封顶 5 行）
第二句字幕
EN: Optional English line（可选，跟在中文条后面）

=== 3-5 ===          ← 第 3 到 5 页共用这些字幕
```

编辑器里点「插入模板」「校验格式」「格式说明」随时自查；详见 [docs/USAGE.md](docs/USAGE.md)。

## 快捷键

| 键 | 作用 |
|---|---|
| F9 / F8 | 下一条 / 上一条（仅逐条模式） |
| F7 | 显示 / 隐藏字幕条 |
| Ctrl+Alt+空格 | 暂停 / 继续滚动 |
| Ctrl+Alt+↑/↓ | 滚动模式手动推 / 退一段 |
| Ctrl+Alt+→/← | 下一页 / 上一页 |
| Ctrl+Alt+R | 回本页开头重滚 |
| Ctrl+Alt+P | 显示 / 隐藏控制台 |
| Ctrl+Alt+X | 临时切换点击穿透（默认关，字幕条可直接拖动） |
| Ctrl+Alt+=/− | 放大 / 缩小字号 |
| Ctrl+Alt+Q | 退出 |
